# 4. Subtasks API — `/api/subtasks`

> File: `app/api/subtasks.py` · Blueprint: `subtasks_bp` · **4 endpoints** · **All JWT-protected**

A subtask document holds an array `subTasks` generated by the LLM from the parent task's description.

---

## 4.1 `POST /api/subtasks/create` — Generate subtasks for a task

- **Auth:** 🔒 JWT
- **Content-Type:** `application/json`
- **Behavior:** verifies task ownership → sets `hasSubtasks: true` on parent → LLM splits
  `task.description` into `subTasks[]` → inserts one subtask document.

| Field | Type | Required | Default |
|-------|------|----------|---------|
| `taskId` | string | ✅ | — |
| `title` | string | ❌ | `"Generated subtasks"` |
| `order` | number | ❌ | `1` |

```json
{ "taskId": "6890abc...", "title": "Weekend chores", "order": 1 }
```

**Responses**

| Code | Body |
|------|------|
| `201` | `{ "subtaskId", "taskId", "title", "done", "order", "subTasks": [...] }` |
| `400` | `{ "message": "taskId is required" }` |
| `404` | `{ "message": "Task not found" }` |
| `500` | `{ "message": "Internal server error" }` |

---

## 4.2 `GET /api/subtasks/task/<task_id>` — List subtasks of a task

- **Auth:** 🔒 JWT (ownership of parent task is checked)

**Responses:** `200` array of
`{ "subtaskId", "title", "order", "done", "subTasks": [...] }` · `404 Task not found` · `500`

```bash
curl http://127.0.0.1:5000/api/subtasks/task/6890abc... \
  -H "Authorization: Bearer <access_token>"
```

---

## 4.3 `PUT /api/subtasks/<subtask_id>` — Update a subtask

- **Auth:** 🔒 JWT (verified via parent task ownership)
- **Content-Type:** `application/json`

**Allowed fields:** `title`, `done`, `order`

```json
{ "done": true }
```

**Responses:** `200 { "message": "Subtask updated" }` · `404 { "message": "Subtask not found" }` · `500`

---

## 4.4 `DELETE /api/subtasks/task/<task_id>` — Delete ALL subtasks of a task

- **Auth:** 🔒 JWT (parent task ownership checked first)
- **Behavior:** `delete_many` on `taskId`, then resets parent `hasSubtasks = false`.

**Responses**

| Code | Body |
|------|------|
| `200` | `{ "message": "2 subtask(s) deleted for taskId 6890abc..." }` |
| `404` | `{ "message": "Task not found" }` |
| `500` | `{ "message": "Internal server error" }` |

**⚠️ Note:** there is **no single-subtask delete** endpoint — deletion is bulk per task.
